# Slide deck template

10 slide types at 1920×1080, structured base → starfield → content. Each `.html` is a standalone slide linking `../../styles.css` + `slide.css`.

cover · agenda · section · speaker · body · stat · comparison · code · image (light theme) · closing.

Copy the ones you need, keep the `.dk-stage` shell + `slide.css`, and swap the content. Mascots load from `../../assets/mascot/`.

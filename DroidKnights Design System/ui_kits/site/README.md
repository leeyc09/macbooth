# Marketing landing site

Interactive recreation of the DroidKnights 2026 landing page, composed from the design-system components (`window.DroidKnightsDesignSystem_0cd94e`).

Screens: sticky nav · hero · stats band · filterable session tracks · speaker grid · sponsor tiers · ticket-signup modal · footer CTA.

`index.html` loads React + Babel + `_ds_bundle.js`. Mascots load from `../../assets/mascot/`.

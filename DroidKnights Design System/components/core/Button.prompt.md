Primary action button; use for CTAs and nav actions across slides, site, and collateral.

```jsx
<Button variant="primary" size="lg" arrow>제안서 요청하기</Button>
<Button variant="secondary">등급 안내 보기</Button>
```

Variants: `primary` (brand gradient + glow), `secondary` (glass), `ghost` (outline). Sizes `md` / `lg`. Set `arrow` for a trailing →, `icon` for a leading node, `href` to render an anchor.

Template file

Use it in pibooth

  1. Save the JSON as classic-strip.json next to your config, e.g. ~/.config/pibooth/.
  2. Point the template option at it (add more paths to offer a choice after each shoot):
    [PICTURE]
    template = ("classic-strip.json", "fancy.xml")
  3. Enable the plugin under [GENERAL] plugins and restart pibooth.

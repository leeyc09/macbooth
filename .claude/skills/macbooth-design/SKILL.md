Full guide for humans: `docs/DESIGN.md`. Brand rules: the `droidknights-design` skill
(`DroidKnights Design System/readme.md`, tokens in `tokens/*.css`).

## Where the look comes from

- `pibooth/themes/<name>/theme.json` is the single source for the booth: colors, fonts,
  assets, booth texts (`texts.ko`), event info (`event`), share page texts (`share`),
  frame list (`templates`). Its values are copied from the design system tokens
  (`--dk-blue` → `colors.blue`, ...): when the design system changes, update theme.json.
- Generated by `tools/build_theme.py` — never edit by hand, rebuild instead:
  `templates/<name>-4.json`, `templates/<name>-1.json`, `assets/booth-background.jpg`,
  `assets/booth-capture-group.png`, `assets/booth-processing.png`, `share-worker/src/theme.js`.
  The drawing code is the `galaxy` style in `tools/build_theme.py`.
- Not driven by the theme (hard-coded CSS variables copied from the tokens):
  `factory/index.html`, `factory/remote.html`, `factory/settings.html`, `factory/assets/`.
- Hand-made frames: JSON format documented in `JsonTemplate` of
  `plugins/pibooth_picture_template.py` (normalized 0..1 rects, 2400x3600 portrait).
  A theme's `templates` list wins over `[PICTURE] template` of pibooth.cfg.

## Loop for every change

1. Edit `theme.json` (or the `galaxy` style code, or a template JSON).
2. Rebuild: `~/pibooth-venv/bin/python tools/build_theme.py <theme> --worker share-worker/src/theme.js`
3. Preview: `~/pibooth-venv/bin/python tools/preview_theme.py <theme> --out preview --screens`,
   then Read the images in `preview/` and check them against the brand rules
   (dark space base, blue→purple only, mascot never recolored and one per view,
   Korean text fits, nothing cut at the 4x6 print edges).
4. Iterate until it looks right, then run
   `SDL_VIDEODRIVER=dummy ~/pibooth-venv/bin/python -m pytest tests/test_theme.py tests/test_layout.py`
   and `cd share-worker && npm test`.
5. Tell the user what must be redeployed: the share Worker (`npm run deploy`) when
   `theme.js` changed, the app (`packaging/build_mac.sh`) for the booth Macs.

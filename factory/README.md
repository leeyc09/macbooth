# MacBooth 로컬 페이지 가이드

pibooth를 실행하면 `pibooth_factory` 플러그인이 이 맥에서 작은 웹 서버(기본 포트 `8770`)를 띄웁니다.
이 서버가 아래 세 페이지를 제공합니다.

| 페이지 | 주소 | 용도 |
|---|---|---|
| 사진 공장 | `/` | 큰 화면에 틀어두는 사진 인쇄 애니메이션 |
| 설정 | `/settings` | 컷 수, 프레임, 카운트다운, 업로드 같은 설정 변경 |
| 아이패드 리모컨 | `/remote` | 촬영 시작, 컷 수, 프레임 선택 버튼과 사진 받기 QR |

기본 설정에서는 **이 맥에서만** 열립니다 (`http://localhost:8770/...`).
아이패드 같은 다른 기기에서 열려면 아래 "같은 네트워크에서 사용하기"를 따라 하세요.

---

## 같은 네트워크에서 사용하기 (아이패드 리모컨)

### 1. 맥에서 접속 허용 바꾸기

1. 맥 브라우저에서 `http://localhost:8770/settings`를 엽니다.
2. **연결** 항목에서 설정합니다.
   - **접속 허용**: `같은 네트워크 (아이패드 리모컨)`
   - **설정 화면 PIN**: 숫자 4~6자리 (예: `2026`)
     네트워크에 열면 같은 와이파이의 누구나 설정 화면에 들어올 수 있으니 꼭 정하세요.
     리모컨과 사진 공장 화면은 PIN 없이 열립니다.
3. **저장**을 누르고 **pibooth를 다시 시작**합니다. 이 두 항목은 재시작해야 적용됩니다.

`pibooth.cfg`를 직접 고쳐도 됩니다.

```ini
[FACTORY]
host = 0.0.0.0
settings_pin = 2026
```

### 2. 맥의 IP 주소 확인

가장 쉬운 방법: pibooth 대기 화면 오른쪽 위의 **MacBooth 주소** 패널(시작 후 30초 동안 표시, **I 키**로 보이기/숨기기)이나 창 제목에 주소가 나옵니다. 패널의 QR을 아이패드로 찍으면 리모컨이 바로 열립니다.

직접 확인하려면 다음 둘 중 하나를 씁니다.

- **시스템 설정 → Wi-Fi → 연결된 네트워크의 [세부사항]** → `IP 주소` (예: `192.168.20.116`)
- 터미널:
  ```bash
  ipconfig getifaddr en0
  ```

### 3. 아이패드에서 열기

1. 아이패드를 **맥과 같은 와이파이**에 연결합니다.
2. Safari에서 `http://<맥 IP>:8770/remote`를 엽니다. 예: `http://192.168.20.116:8770/remote`
3. 오른쪽 위 상태 표시가 `대기`로 나오면 연결된 것입니다.

### 4. 앱처럼 쓰기 (권장)

- **홈 화면에 추가**: Safari 공유 버튼 → **홈 화면에 추가**. 주소창 없이 전체 화면으로 열립니다.
- **화면 잠금 끄기**: 설정 → 디스플레이 및 밝기 → **자동 잠금 → 안 함**
- **사용법 유도(Guided Access)**: 손님이 리모컨 화면을 벗어나지 못하게 합니다.
  1. 설정 → 손쉬운 사용 → **사용법 유도** 켜기 → 암호 설정
  2. 홈 화면에 추가한 리모컨을 연 상태에서 **측면(또는 홈) 버튼을 세 번** 누르고 **시작**
  3. 끝낼 때도 버튼을 세 번 누르고 암호를 입력합니다.

### 5. 방화벽 (켜져 있는 경우)

맥 방화벽이 켜져 있으면 pibooth 시작 시 **"python3이 수신 연결을 허용하도록 하겠습니까?"** 창이 뜹니다. **허용**을 누르세요.
이미 거부했다면 시스템 설정 → 네트워크 → 방화벽 → 옵션에서 `python3`를 **수신 연결 허용**으로 바꿉니다.

## 행사장 네트워크 팁

- **IP 고정**: 와이파이에 다시 연결하면 맥 IP가 바뀔 수 있습니다. 공유기 설정의 **DHCP 예약(고정 IP)**에 맥을 등록하거나,
  맥에서 시스템 설정 → Wi-Fi → [세부사항] → TCP/IP → **수동으로 IP 주소 설정**을 쓰세요. IP가 바뀌면 아이패드의 홈 화면 바로가기도 다시 만들어야 합니다.
- **게스트 와이파이 주의**: 행사장이나 호텔의 게스트 와이파이는 **기기끼리 통신을 막는 경우(클라이언트 격리)**가 많습니다.
  아이패드에서 페이지가 안 열리면 이 문제일 가능성이 큽니다. 다음 방법 중 하나를 쓰세요.
  - **소형 공유기 하나 가져가기**: 맥과 아이패드만 연결합니다. 인터넷이 없어도 리모컨과 사진 공장은 동작합니다. R2 업로드와 공유 페이지는 인터넷이 필요합니다.
  - **아이폰 개인용 핫스팟**: 맥과 아이패드를 아이폰 핫스팟에 함께 연결합니다.
- **인터넷이 끊겨도**: 리모컨, 사진 공장, 설정 화면은 계속 동작합니다. 업로드만 실패하고, 업로드가 끝나지 않은 사진은 맥에서 지우지 않습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 아이패드에서 페이지가 안 열림 | 같은 와이파이인지, `접속 허용`을 바꾼 뒤 pibooth를 재시작했는지, 주소의 IP와 `:8770` 확인 |
| 맥에서는 열리는데 아이패드만 안 됨 | 게스트 와이파이의 기기 간 통신 차단(위 팁 참고), 맥 방화벽 허용 여부 |
| 리모컨 상태가 `연결 끊김` | pibooth가 꺼졌거나 맥 IP가 바뀜. pibooth 실행 여부와 IP 다시 확인 |
| 버튼이 눌리지 않음 | 촬영 중에는 버튼이 비활성화됩니다. `대기` 상태에서 다시 누르세요 |
| 설정 화면에서 PIN을 물음 | `설정 화면 PIN`에 정한 번호 입력 (리모컨에는 필요 없음) |
| 시작할 때 카메라 선택 창이 뜸 | 설정의 **사용할 카메라**를 `MacBook`처럼 이름 일부로 정하면 선택 창 없이 그 카메라를 씁니다 |
